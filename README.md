# Consulta de CEP

Projeto desenvolvido em Python para consultar endereços brasileiros utilizando a API pública ViaCEP.

## Funcionalidades

- Buscar um endereço a partir de um CEP
- Exibir rua, bairro, cidade e estado
- Validar o formato do CEP
- Identificar CEP inexistente
- Guardar histórico de buscas
- Exportar o histórico para um arquivo JSON
